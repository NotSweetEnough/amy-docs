# Support

Ask questions and report problems as an issue on GitHub: [Issues](https://github.com/NotSweetEnough/amy-docs/issues). Issues are public.

Include:

- the Amy extension version (**Organization settings > Extensions**) and the backend version (`/api/health` reports it as `version`);
- what you did, what you expected and what happened;
- the **correlation ID** from the error message, if there is one.

Never include API keys, client secrets, tokens, Wiki or work-item content, or your backend's URL in an issue. To report a security vulnerability, follow [SECURITY.md](SECURITY.md#reporting-a-vulnerability) instead.
